# 10545 - [Bug] App crashes on startup if system language is set to Marathi (मराठी)

- URL: https://github.com/ankidroid/Anki-Android/issues/10545
- State: closed
- Author: quanta-kt
- Created: 2022-03-16T08:55:28Z

---

###### Reproduction Steps

1. Set your system language to Marathi
2. Start the app

###### Workaround

1. Temporarily set system language to English
2. Open Anki droid and set it's language to English from in-app settings
3. Set system language back to what you use

This way the app works, but only if you are willing to use it in English. Well, that's at-least better than completely an unusable app.


###### Expected Result

The app to start normally


###### Actual Result

Crashes on start-up
