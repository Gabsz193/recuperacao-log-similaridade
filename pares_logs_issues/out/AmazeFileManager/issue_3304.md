**Describe the bug**
crash and exit when try to use certificate installer to open file

**To Reproduce**
Steps to reproduce the behavior:
1. Click into "Internal Storage"
2. Click on the button "Add a file" in the lower right corner
3. Add a file named "www.google.com"
4. Click on "search" in the upper right corner
5. Type in "www.google.com" to search for it
6. Click on the file name "www.google.com" in the search results
7. Click on "Just Once" and choose to open it with certificate installer
8. Prompt "Certificate Installer has stopped."
9. Crash and exit

**Expected behavior**
The application should not crash and exit because it cannot be opened with the certificate installer.
